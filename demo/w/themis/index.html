What it is

THEMIS answers questions about UK capacity law: the Mental Capacity Act 2005, the Court of Protection Rules and the Code of Practice. I built it for a setting where a wrong answer has real consequences, so its first job is to know when not to answer.

It runs entirely on one machine with local models. It quotes the law before it says anything about it, and it tells you plainly when it does not know.

How it works
  • Refuses advice. "Will I win?" or "what should I do?" is turned away before any search.
  • Hybrid retrieval. Meaning-based search and exact keyword search (section numbers, case names) run together and are merged.
  • Abstains. If the best passage falls below a confidence threshold, it says so instead of guessing.
  • Quote, then point. Every point follows the verbatim text it rests on, with a citation.
  • Local models. Embedding and language model run on the machine; nothing is sent out.
