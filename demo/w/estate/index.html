The second brain
One vault · one drive · one writer

The canonical store for everything I know and everything my agents produce. It lives on one drive on the M1; every other machine is a client. There is no second copy.

My notes, apart from machine output

Agents file into their own folders and the lake. Only I promote something into the notes, so search ranks human work first.

A checker that wins

The lint runs before and after every change. If the written rules and the checker disagree, the checker wins.

Never rename, never delete

A superseded note is archived with a pointer to what replaced it. Some places are closed to every agent, by path.

Five tiers

vault/ human knowledge, by domain
lake/ machine output, append-only
media/ files, stored once by hash
evidence/ sealed, no agent writes
system/ the rules and the checker
